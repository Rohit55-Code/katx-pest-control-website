## 📖 About

**KATX** is a pest control company's business website — built end-to-end as a **freelance project**, independent of my regular employer work. The site is a single-page design covering their services, common pests handled, process, and a contact section, with a clean dark-teal brand identity.

---

## ✨ Features

- 🎨 Custom dark-teal brand identity, built from scratch for the client
- 📱 Fully responsive layout (dedicated `responsive.css` for breakpoints)
- 🖱️ Smooth in-page navigation via anchor links (`#services`, `#pests`, `#why-us`, `#cleaning`, `#contact`)
- ⚡ Lightweight — no frameworks, pure HTML/CSS/JS

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (`style.css` + `responsive.css`)
- Vanilla JavaScript (`script.js`)
